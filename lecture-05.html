Список и кортеж

Семь переменных s1, s2, …, s7 циклом не перебрать: цикл обходит элементы одной последовательности, а не разные имена. Нужна одна переменная, которая хранит много значений по порядку.

Как хранить в программе семь последовательностей, а не одну?

Подсказка: s1, s2, …, s7: как перебрать их циклом?

Перебрать циклом можно элементы одной последовательности, а не разные имена. Нужна одна переменная, которая хранит все семь значений по порядку. Это список. Кто предложит склеить последовательности в строку через пробел и вызвать split(), почти прав: split() из лекции 2 как раз возвращает список.

Список — последовательность значений, записанных через запятую в квадратных скобках: [10, 20, 30]. Значения списка называют элементами; они бывают любого типа, даже списками.

Пустой список записывают как []. Со списком работает все, что вы делали со строкой как с последовательностью: индекс, len(), in и цикл for. Список можно записать на нескольких строках кода: пока скобка не закрыта, Python считает это одной инструкцией. В примере собраны семь последовательностей из задачи Rosalind. Запустите его, затем допишите print(seqs[0][0]) и запустите снова.

Отличия от строки видны в выводе. seqs[0] дает целую последовательность, а не букву, а len(seqs) считает элементы, а не буквы. Оператор in сравнивает элементы целиком: "CAAC" in seqs дает False, хотя такой кусок есть в "GGGCAACT".

Список удобно представлять рядом ячеек. Над ячейкой стоит индекс от начала, с нуля: он показывает, на сколько шагов элемент отстоит от начала. Под ячейкой стоит индекс от конца: последний элемент имеет номер -1. Индексы списка устроены так же, как индексы строки в лекции 2.

Список можно изменить

Элементу списка можно присвоить новое значение, и список изменится на месте. Метод append(x) дописывает x в конец того же списка, новый список не создается. Строку так изменить нельзя. Поэтому список называют изменяемым типом, а строку неизменяемым.

Пример печатает измененный список, а последняя строка останавливает программу: TypeError: 'str' object does not support item assignment. Методы строк из лекции 2 никогда не меняли строку, а возвращали новую: для строки иначе нельзя.

Кортеж

Кортеж (tuple) — неизменяемая последовательность значений, записанных через запятую. Кортеж создает запятая, а скобки нужны только для ясности.

Кортеж удобен для записи из нескольких полей: имя последовательности, длина и GC-состав в процентах. При печати Python показывает кортеж в круглых скобках. Индексы и len() работают как у списка, а изменить элемент нельзя: снова TypeError, теперь 'tuple' object does not support item assignment.

("ATG") не кортеж, а обычная строка в скобках: скобки только группируют выражение, и len() считает буквы. Кортеж из одного элемента пишут с запятой: ("ATG",).

Кортеж тоже удобно рисовать ячейками, только в круглых скобках. Индексы считаются так же, как у списка, а подписи под ячейками показывают главное отличие: поля записи разного смысла и типа.

Зачем Python два похожих типа, разработчики объясняют в официальном FAQ. Список похож на массив: элементы одного рода, их число может меняться, а обрабатывают их по одному. Кортеж похож на запись: несколько связанных значений, часто разных типов, которые обрабатывают вместе.

Правило не жесткое: в кортеж можно положить однородные числа, а в список разнородные значения. Речь о том, как типы задуманы. Кортеж может быть ключом словаря, а список не может; словари будут в следующей лекции.

Кортеж неизменяем, но список внутри кортежа меняется. После rec = ("R1", [1, 2]) вызов rec[1].append(3) выполняется, и print(rec) выводит ('R1', [1, 2, 3]). Кортеж по-прежнему ссылается на тот же список, изменился сам список.

Два имени, один список

Раз список можно менять, возникает вопрос, которого со строками не было. Сделаем b = a и допишем элемент в b:

a = ["ATCC", "GGGC"]  # создали список
b = a                 # второе имя
b.append("AAGC")      # дописали в b

Изменится ли список a, если дописать элемент в b?

Подсказка: после y = x и x = x + 1 переменная y у чисел не меняется. Так ли со списком?

Изменится: print(a) выведет ['ATCC', 'GGGC', 'AAGC']. Аналогия с числами подводит: b = a не копирует список, а дает ему второе имя. Почему так, объясняет схема ниже.

Список a изменился. Переменная в Python не коробка, в которую кладут список, а ярлык на объекте. Первая строка создает список и вешает на него ярлык a. Вторая строка не копирует список, а вешает на тот же объект второй ярлык b. Элемент дописан через b, и через a виден тот же, уже измененный список.

a = ["ATCC", "GGGC"]
b = a
b.append("AAGC")
print(a)

Образ ярлыка перестает быть точным в одном месте: настоящий ярлык висит снаружи предмета, а в Python ссылки есть и внутри объектов. Элемент списка тоже ссылка на объект; это понадобится для вложенных списков в конце лекции.

Ссылка — связь имени с объектом. Если у одного объекта два имени, говорят, что у него есть псевдоним (alias).

Независимый список копируют явно. Метод copy() и срез a[:] без обоих индексов строят новый список с теми же элементами. Оператор is проверяет, тот ли это самый объект, а == проверяет, равны ли значения.

b и a оказались одним объектом, а c и a двумя разными объектами с равными значениями. Поэтому append() к копии c оригинал не трогает.

Кажется: b = a кладет в b копию списка.

На самом деле: присваивание никогда не копирует данные. b = a дает тому же списку второе имя. Копию делают явно: a.copy() или a[:].

Для чисел и строк общий объект ничем не опасен: их нельзя изменить. После y = x и x = x + 1 переменная y прежняя, потому что x + 1 создает новый объект и перевешивает на него ярлык x. Правило присваивания одно для всех типов, разница только в том, можно ли изменить сам объект.

Третий способ копирования дает функция list(a). Все три способа строят поверхностную копию: новый внешний список с теми же элементами. Если элементы сами списки, они остаются общими; к этому мы вернемся в разделе о консенсусе.

Третья строка изменила сам список, на котором висят оба ярлыка. Четвертая строка в нем ничего не меняет: она создает новый список ['T'] и перевешивает на него ярлык b, а a остается на старом. Вариант ['A', 'C'] получился бы, если бы b = a делал копию, ['T'] — если бы присваивание b меняло и a. Последний вариант путает присваивание с append().

Индексы, срезы, методы

Как взять первые три последовательности, а последнюю убрать?

Подсказка: вспомните срез строки из лекции 2: seq[:3].

Первые три дает срез seqs[:3]: срезы списка устроены так же, как срезы строки. Чтобы убрать последнюю, нужен способ изменить сам список, а у строки такого не было. Для этого есть методы списка pop(), remove() и инструкция del; они собраны в таблице ниже.

Из семи последовательностей часто нужны только первые три, а последнюю, ошибочную, надо убрать. Срезы списка устроены так же, как срезы строки из лекции 2: [начало:конец:шаг], начало входит в срез, конец не входит. Разница одна: срез списка строит новый список. Поэтому изменение top в примере не трогает seqs, и по той же причине срез [:] дает копию.

Срез за концом списка ошибки не дает, а индекс за концом дает. Индекс просит один элемент, а срез берет столько, сколько найдется в диапазоне. У трех элементов индексы 0, 1 и 2, поэтому seqs[3] останавливает программу с IndexError.

seqs = ["ATCC", "GGGC", "ATGG"]
print(seqs[1:20])   # ['GGGC', 'ATGG']
print(seqs[3])      # IndexError: list index out of range

Самая частая причина IndexError в том, что индексы начинаются с нуля, и последний индекс на единицу меньше длины. При такой ошибке напечатайте список или его длину. Последний элемент надежнее брать как seqs[-1]: это работает для любой длины, кроме пустого списка.

append, extend, + и +=

Добавить в список несколько элементов можно разными способами, и результат у них разный. append кладет аргумент целиком одним элементом: в a оказался список внутри списка, длина 2. extend дописывает элементы по одному, длина 3. Оператор + склеивает списки, как строки, но строит новый список: c is b дает False.

Запись x += y означает «прибавить y к x». Для чисел это короткая форма x = x + y: n += 1 увеличивает счетчик на единицу. Для списка += дописывает элементы в тот же самый список, как extend.

Разница между += и a = a + [...] видна, когда у списка два имени. После b = a запись a += [3] меняет общий список, и b это видит. Запись a = a + [4] сначала строит новый список, а потом перевешивает на него только ярлык a; ярлык b остается на старом списке.

Привычка из лекции 2 подводит: методы строк возвращали новую строку, и мы писали s = s.upper(). Метод списка append() уже изменил список и вернул None, а присваивание повесило ярлык seqs на None. Метод, который меняет список, вызывают отдельной строкой, без присваивания.

seqs = ["ATCC", "GGGC"]
seqs = seqs.append("TTGG")   # так нельзя
print(seqs)        # None
print(len(seqs))   # TypeError: object of type 'NoneType' has no len()

Список с тремя элементами где-то есть, но имени у него больше нет: seqs теперь означает None, а у None нет длины.

Откуда берутся списки

Метод split() из лекции 2 всегда возвращал список, просто мы его так не называли. А print(range(5)) не показывает числа: диапазон их не хранит, он помнит начало, конец и шаг и выдает числа по одному, когда их просят. Удаление во время обхода

Удалим из списка все последовательности с неизвестной буквой N. Первая версия выглядит правильно, но "NNAT" уцелел. Вторая версия отличается одним символом. Запустите пример и сравните результаты.

Цикл for идет по позициям того же списка, а удаление сдвигает элементы влево. После удаления "NNNN" на позицию 0 встал "NNAT", а цикл перешел к позиции 1, где уже "ATCC". Python об ошибке не сообщает. Если в цикле удаляются элементы, обходят копию seqs[:], а удаляют из оригинала.

Второй способ избежать ошибки: собрать новый список из подходящих элементов. Короче всего это записать включением [s for s in seqs if "N" not in s], о включениях пойдет речь ниже.

Звездочка: остаток в список

Если элементов больше, чем имен, одно имя можно пометить звездочкой: оно соберет все, что не досталось остальным. Звездочка стоит в начале, в середине или в конце. Имя со звездочкой всегда получает список, даже если справа строка. Если на его долю ничего не осталось, список пустой, но ошибки нет.

Звездочка в распаковке может быть только одна: *a, *b = seq дает SyntaxError: multiple starred expressions in assignment. Остаток строки со звездочкой получается списком букв, а не строкой, как у среза seq[1:].

Список кортежей встречается постоянно: каждая строка таблицы представляет собой запись. Цикл for берет записи по одной, и распаковку пишут прямо в его заголовке. В теле вместо rec[0] и rec[1] стоят понятные имена. Пример печатает последовательности с GC-составом больше 45 %.

Распаковка в заголовке цикла подходит, только если каждый элемент состоит ровно из стольких частей, сколько имен. В списке строк элементы не пары: строку из восьми букв Python пытается разложить на два имени и останавливается с ValueError.

Для записей разной длины в заголовке цикла пишут звездочку: for name, *nums in recs:. name получает первое поле записи, а nums список остальных, возможно пустой.

enumerate() и zip()

Нужна и буква, и ее номер. Как обойтись без range(len(s))?

Подсказка: в лекции 4 писали for i in range(len(s)): и внутри цикла брали букву s[i].

Номер и букву удобно получать парой, то есть кортежем, и сразу распаковывать в заголовке цикла. Такие пары выдает функция enumerate(), а пары букв двух последовательностей выдает zip().

В лекции 4 позицию буквы узнавали циклом по индексам for i in range(len(s)):, а букву доставали как s[i]. Это работает, но читается тяжело, и индекс легко сделать на единицу больше нужного. Две встроенные функции выдают кортежи, которые удобно распаковывать в заголовке цикла.

Работу enumerate() удобно представлять как счетчик 0, 1, 2, …, который идет рядом с последовательностью. На каждом шаге функция берет очередной элемент и текущее значение счетчика и складывает их в кортеж: сначала номер, потом элемент.

Сортировка

Как упорядочить последовательности по длине, а не по алфавиту?

Подсказка: "AT" < "GATTACA", ведь "A" < "G": длина не важна.

Обычная сортировка строк идет по алфавиту. Идея «сделать список длин и отсортировать его» близка к ответу, но так теряются сами строки. Нужно сказать Python, по какому признаку сравнивать элементы, а в результат класть сами строки.

Строки Python сравнивает посимвольно, как слова в словаре, и длина при этом не важна: "AT" < "GATTACA", потому что "A" < "G". Поэтому сортировка списка строк упорядочит их по алфавиту. Чтобы упорядочить последовательности по длине, Python нужно сказать, что сравнивать.

Сначала о двух способах сортировать. Метод sort() переставляет элементы в самом списке и, как другие методы, которые меняют список на месте, возвращает None. Функция sorted() исходные данные не трогает, а строит новый отсортированный список; ей можно дать и строку, и кортеж.

Слева sort(): в r = a.sort() попал бы None, а сам a отсортирован. Справа sorted(): в r = sorted(b) лежит новый список, а b прежний. Отсюда правило: от sort() результат не сохраняют, от sorted() сохраняют обязательно.

Обе сортируют по алфавиту. Как сортировать по длине?

Подсказка: у sort() и sorted() есть параметр key=: что в него передать?

В key= передают функцию, которая по элементу вычисляет то, по чему сравнивать. Для длины это len: sorted(seqs, key=len).

Ключ сортировки

Ключ сортировки — значение, которое функция из параметра key вычисляет для каждого элемента. Сравниваются ключи, а в результат попадают сами элементы.

Параметр key= получает функцию одного аргумента, например len. Python вызывает ее один раз для каждого элемента и упорядочивает элементы по ключам. Функцию передают без скобок: key=len, а не key=len(). Со скобками вы бы вызвали ее сами, а вызывать ее должен Python.

Ключом служит и метод, записанный через имя типа: key=str.lower означает «у каждой строки вызвать lower()». str.lower это тот же метод lower(), взятый у типа str: str.lower("Gc") дает "gc", как "Gc".lower(). Поэтому его можно передать как функцию одного аргумента. Параметр reverse=True дает порядок по убыванию. Оба параметра есть и у sort(), и у sorted().

Без ключа строки идут по кодам символов, и все прописные буквы стоят раньше строчных: "gc" оказался последним. С ключом str.lower строки сравниваются в нижнем регистре, а печатаются как были. Строки "AT" и "gc" одной длины, и с key=len они стоят в исходном порядке, даже при reverse=True.

Сортировка в Python устойчивая: при равных ключах элементы сохраняют тот порядок, в котором были.

Ключом может быть и метод конкретного объекта: seq.count для буквы возвращает, сколько раз она встречается в seq. Так в конце лекции найдем самую частую букву столбца. Свои функции появятся в лекции о функциях, а до тех пор ключ берем из встроенных функций и методов.

Метод sort() возвращает None нарочно: копировать список ради сортировки расточительно, а None напоминает, что исходный порядок потерян.

Сортировка кортежей

Кортежи сравниваются поле за полем: сначала первые поля, а если они равны, то вторые, и так далее. Такой порядок называют лексикографическим. Список записей (gc, name) поэтому сортируется по GC-составу, а записи с равным GC упорядочиваются по имени. Поле, по которому нужно сортировать, ставят в кортеже первым.

С reverse=True порядок переворачивается целиком: при равном GC имена тоже идут по убыванию.

Если на одной позиции кортежей смешаны числа и строки, сравнение дает TypeError: число со строкой Python не сравнивает.

max() и min() с ключом

Параметр key есть и у max() и min() из лекции 4. max(seqs, key=len) отвечает на вопрос «какая последовательность самая длинная», и в ответе сама строка, а не ее длина. При равных ключах возвращается первый из элементов: короче всех "AT" и "GC", и min вернул "AT". Без ключа max сравнивает строки по алфавиту, и максимальной оказалась самая короткая "GC".

seqs = ["ATCCAGCT", "AT", "GATTACA", "GC"]
print(max(seqs, key=len))   # ATCCAGCT
print(min(seqs, key=len))   # AT
print(max(seqs))            # GC: по алфавиту

В лекции 4 максимум искали шаблоном «лучшее на данный момент». max(..., key=...) делает то же одной строкой. Для пустого списка max дает ValueError.

Ключи равны 3, 2, 3, 2. Сначала идут слова длины 2, потом 3, а внутри каждой группы сохраняется исходный порядок: "GC" стоял раньше "CA" и остался раньше, хотя по алфавиту "CA" меньше. Первый вариант дополнительно сортирует по алфавиту, второй путает направление, а [2, 2, 3, 3] сортирует сами длины.

Списковые включения

Пустой список, цикл и .append(): можно ли короче?

Подсказка: lens = [], for s in seqs:, lens.append(len(s)).

Можно: списковое включение записывает те же части одной строкой, [len(s) for s in seqs]. Три строки шаблона накопителя ради одной мысли становятся одним выражением.

Новый список из старого обычно строят шаблоном накопителя из лекции 4: пустой список, цикл и append() в теле. Несколько строк уходит на одну мысль «список длин последовательностей без буквы N». Для этого у Python есть короткая запись.

Списковое включение — выражение в квадратных скобках, которое строит новый список: [выражение for x in последовательность if условие].

Части включения те же, что у цикла, только переставлены: сначала то, что кладут в список, потом for, потом условие. Читать включение удобно вслух: «длина s для каждого s из seqs, если в s нет N». Пример строит один и тот же список обоими способами.

Без условия включение делает новый элемент из каждого старого, и новый список получается той же длины, что исходный. Исходный список не меняется. Выражением может быть что угодно: вызов функции, метода, даже кортеж.

seqs = ["ATCCAGCT", "GGGCAACT", "TTGG"]
print([len(s) for s in seqs])        # [8, 8, 4]
print([s.lower() for s in seqs])     # ['atccagct', 'gggcaact', 'ttgg']
print([(s, len(s)) for s in seqs][2])   # ('TTGG', 4)

С условием включение работает как фильтр: элемент попадает в новый список, только если условие верно. Первое включение в примере отбирает последовательности, где буква G встречается хотя бы дважды. Второе решает задачу Rosalind SUBS из лекции 4 одной инструкцией: перебирает позиции начала окна длины 4 и оставляет те, где окно совпало с мотивом. i + 1 переводит индекс Python в позицию Rosalind, и ответ [2, 4, 10] совпадает с ответом задачи.

range(len(s) - 3) перебирает только позиции, с которых мотив длины 4 помещается целиком. Включение можно писать на нескольких строках, пока скобка не закрыта.

Во включении может быть несколько for. Они идут в том же порядке, что вложенные циклы: первый внешний, второй внутренний. Поэтому сначала идут все пары с A, потом все пары с C. Выражение-кортеж (a, b) обязательно берут в скобки.

pairs = [(a, b) for a in "AC"
         for b in "GT"]
print(pairs)
# [('A', 'G'), ('A', 'T'), ('C', 'G'), ('C', 'T')]

Переменная цикла for остается после цикла и хранит последнее значение. Переменная включения существует только внутри квадратных скобок: обращение к ней после включения дает NameError.

Когда включение хуже цикла

Включения удобны, пока они короткие. Б. Слаткин в книге «Effective Python» советует оставлять во включении не больше двух управляющих частей: два for или for и if. Если частей больше, пишите обычный цикл: строк больше, но каждую можно прочитать. Оба варианта ниже отбирают из строк матрицы с суммой не меньше 10 числа, кратные 3, и дают [6, 9].

m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
# плохо: два for и два if в одной строке
r = [x for row in m if sum(row) >= 10
     for x in row if x % 3 == 0]
# хорошо: то же циклами
r = []
for row in m:
    if sum(row) >= 10:
        for x in row:
            if x % 3 == 0:
                r.append(x)
print(r)   # [6, 9]

От FASTA к консенсусу

В FASTA семь последовательностей. Как получить их консенсус?

Подсказка: консенсус: строка из самых частых букв каждой позиции.

Последовательности нужно хранить вместе и обрабатывать по позициям: разобрать FASTA в список, разложить по столбцам, посчитать буквы в каждом столбце и взять самую частую. Эти четыре шага описаны ниже.

Задача Rosalind CONS: дано несколько последовательностей одинаковой длины в формате FASTA. Для каждой позиции нужно найти самую частую букву и сложить из этих букв строку. Задачу решают за четыре шага, и на каждом шаге данные хранятся по-своему:

  1. текст FASTA разбирают в список записей (id, seq);
  2. последовательности раскладывают по столбцам: zip(*seqs);
  3. в каждом столбце считают буквы A, C, G и T, получается профиль;
  4. из каждого столбца берут самую частую букву, получается консенсус.

FASTA в список записей

Файлы читать мы пока не умеем, поэтому текст FASTA задан строкой в тройных кавычках. Метод split() режет ее по пробелам и переводам строк. Здесь каждая запись занимает ровно две строки, имя и последовательность. Поэтому срез с шагом 2 от нулевого места дает все имена, а от первого все последовательности. Включение со срезом x[1:] снимает с имен знак >, а zip склеивает имена и последовательности в пары.

У приема есть ограничения. split() без аргумента режет и по пробелам, а настоящая строка описания в файлах NCBI содержит пробелы после идентификатора. Кроме того, последовательность в настоящем FASTA часто разбита на несколько строк. Для таких файлов нужен цикл по строкам с проверкой line.startswith(">"), он появится в лекции о файлах. В примере задачи Rosalind CONS каждая последовательность записана одной строкой, и прием работает.

Вложенный список: матрица

Вложенный список — список, элементы которого тоже списки. Если все внутренние списки одной длины, вложенный список называют матрицей.

Элемент m[1] сам является списком, поэтому к нему можно приписать второй индекс. Первый индекс выбирает строку, второй выбирает элемент в этой строке, то есть столбец. Запустите пример, затем напечатайте m[0][1].

Отдельного типа «матрица» среди встроенных типов Python нет: это обычный список списков. Для вычислений с матрицами служит библиотека NumPy с многомерным массивом ndarray; в курсе ее нет.

Строки матрицы через умножение

Чтобы считать профиль вручную, хочется заранее завести матрицу нулей. Список можно умножить на число: [0] * 3 дает три нуля. Но если так же умножить строку матрицы, получится ловушка. Запустите пример.

[[0] * 3] * 2 не делает две строки, а кладет во внешний список две ссылки на одну и ту же строку. Меняем одну ячейку, и меняются обе строки. Строки матрицы строят включением: оно на каждом шаге создает новую строку.

Ссылки живут не только в именах, но и в элементах списка. С числами [0] * 3 безопасно: числа неизменяемы. А копия bad[:] не помогла бы: это поверхностная копия, она строит новый внешний список, но строки оставляет общими. После m = [[1, 2], [3, 4]] и c = m[:] вызов c[0].append(9) виден и в m. Копию матрицы делают включением: [row[:] for row in m].

Профиль и консенсус по столбцам

zip(*seqs) дает восемь столбцов. Строку профиля для каждой буквы строит включение: в каждом столбце эту букву считает метод count(), он есть и у кортежа. Каждая строка профиля оказывается новым списком, поэтому строки не связаны. Профиль получается матрицей 4 × 8.

Самую частую букву столбца находит max с ключом. Перебираются буквы "ACGT", а ключом служит метод count текущего столбца: c.count без скобок для каждой буквы вернет, сколько раз она встречается в столбце c. max возвращает саму букву, а не число. Строка cons растет на букву за шаг: для строк += означает cons = cons + ....

При ничьей max возвращает первую из букв с наибольшим числом в порядке "ACGT". Rosalind в этом случае принимает любой консенсус. Запустите пример: профиль и консенсус ATGCAACT совпадают с ответом задачи Rosalind CONS.

Вектор признаков — список чисел, которые описывают один объект. Каждое число дает признак объекта: длину, GC-состав, число букв A.

Профиль описывал позиции. Часто нужно другое: описать каждую последовательность несколькими числами, чтобы сравнивать последовательности или подать их в программу машинного обучения. Определение взято из глоссария библиотеки scikit-learn. Список векторов образует матрицу признаков X: строка описывает последовательность, столбец описывает признак.

seqs = ["ATCCAGCT", "GGGCAACT", "TTGGAACT"]
X = [[s.count(b) for b in "ACGT"]
     for s in seqs]
print(X)       # [[2, 3, 1, 2], [2, 2, 3, 1], [2, 1, 2, 3]]
col_g = [v[2] for v in X]   # столбец признака G
print(col_g)   # [1, 3, 2]

Внутреннее включение строит один вектор, внешнее повторяет это для каждой последовательности. Сравните с профилем: там строки соответствуют буквам, а столбцы позициям.

  • sorted() с ключом и списковые включения строят новые списки.
