# Язык программирования Python: лекции

Интерактивный сайт с лекциями курса «Язык программирования Python» (профиль «Биоинформатика», Академический университет им. Ж. И. Алферова, 2026).

**Сайт:** https://spbau-bioinf.github.io/python-lectures/

Лекции идут от первых программ до файлов и сквозного проекта «Анализ биологических последовательностей». К каждой лекции есть практическая работа: [сайт практик](https://spbau-bioinf.github.io/python-practice/).

## Что есть на сайте

- **Текст лекции** с разделами, оглавлением и блоками «Подробнее» для тех, кто хочет глубже.
- **Презентация лекции** прямо на странице: слайды с анимациями шагами, как на лекции; F — во весь экран, O — обзор слайдов.
- **Запуск кода прямо в браузере.** Любой пример можно изменить и запустить, устанавливать Python не нужно.
- **Мини-тесты** по ходу лекции с разбором каждого ответа.
- **Разборы задач** из презентации с проверкой собственного решения.
- **Итоговый тест** в конце лекции.
- **Прогресс:** отметки о пройденных тестах и задачах на главной странице.
- **Светлая и темная темы.**

## Как пользоваться

1. Откройте сайт: на главной программа курса и ваш прогресс.
2. Выберите открытую лекцию и читайте по порядку, запуская примеры и отвечая на мини-тесты.
3. Пройдите итоговый тест в конце лекции.
4. Закрепите материал на практике: ссылка на нее есть у каждой лекции.

**Что нужно:** современный браузер (Chrome, Firefox, Edge, Safari) и интернет. Python для запуска кода загружается в браузер при первом запуске, это занимает 10–30 секунд.

**Где хранится прогресс.** Только в вашем браузере, на сервер ничего не отправляется. Чтобы продолжить на другом компьютере, скачайте файл прогресса кнопкой «Скачать прогресс» и загрузите его там кнопкой «Загрузить прогресс».

## Для преподавателя: публикация и обновление

Страницы собираются Skill lecture-python-site и проверяются его скриптами (`check_site.py`); вручную файлы лучше не править, иначе проверки разойдутся с сайтом.

- **Публикация:** Settings → Pages → «Deploy from a branch», ветка `main`, папка `/ (root)`.
- **Какие лекции открыты:** файл `assets/course.js`. Лекция с `"soon": true` и без `file` показывается с меткой «Скоро».
- **Обновление:** в папке репозитория выполните `git add .`, `git commit -m "Что изменилось"`, `git push`. Сайт обновится через 1–2 минуты; если видна старая версия, обновите страницу с Ctrl+F5.
- **Просмотр на своем компьютере:** в Windows двойной щелчок по `Запустить сайт.bat` (в репозиторий не входит) или `python -m http.server` в папке сайта и адрес http://localhost:8000. Открывать файлы двойным щелчком нельзя: браузер не запустит Python из локального файла.
- **Идентификаторы тестов и задач** (`data-id`) после публикации не меняют: по ним хранится прогресс студентов.
